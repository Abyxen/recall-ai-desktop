# Troubleshooting

- **Setup cannot find Python:** Python 3.15 is not the verified runtime. Install Python 3.11 64-bit, or pass its absolute executable path to `setup.ps1 -Python`. The setup script also recognizes the available Astral Python 3.11.17 runtime tag. Read setup errors; `run.bat` keeps failures visible.
- **Virtual environment has no pip:** setup runs `python -m ensurepip --upgrade`. This repairs environments originally created with `uv venv`. Alternatively use `uv pip install --python .venv\Scripts\python.exe -r requirements-lock.txt`.
- **Model unavailable:** start Ollama and use Settings → Test connection. Confirm `ollama list`, the model name, endpoint and timeout. Retrieval/library/saved study features still work. An embedding server is needed for new semantic indexing and semantic queries; blank embedding model and re-indexing restores offline lexical retrieval.
- **No matching evidence:** choose the relevant scope, use specific terms, or re-index. A DOCX is one section; text chapters can be selected by topic or an exact passage within an indexed chunk. Generated material uses a bounded context, not the entire library at once.
- **Embedding configuration changed:** re-index each affected document. Failed re-indexing leaves the previous index intact. Partially changed libraries can contain old fingerprints; only chunks matching the active embedding fingerprint are searched.
- **Import error:** files must be supported, nonempty, within limits and readable. Unlock encrypted PDFs. Re-export corrupt Office/PDF files. TXT/Markdown support UTF-8 and UTF-16; convert legacy encodings to UTF-8. Duplicate detection compares SHA-256 contents, not file names.
- **Image/scanned PDF has no text:** optional OCR requires Tesseract; PDFs additionally require PyMuPDF. Without these, import a searchable PDF or another supported text source. OCR was not validated in the delivered environment.
- **No due flashcards:** turn off Due cards only, check the deck filter and review dates. Ratings schedule future dates, so a reviewed card usually disappears from today's list.
- **Generated JSON invalid:** Recall retries at most three times. Try 1–3 questions, a shorter source or a different instruct model. Quote mismatches, duplicate questions, invalid choices and missing rubric phrases are rejected. Nothing is partially saved on failed generation.
- **Free-text score looks wrong:** phrase coverage is provisional and can miss paraphrases or negation. Compare expected answers, rubric and evidence; use it as revision guidance. Calculation checking cannot validate model-generated derivations.
- **Executable will not start:** keep `_internal` beside `RecallAI.exe`; copy the whole distribution folder. The app is unsigned and has not been tested on a second clean Windows machine. Launch the source via `run.bat` for a visible traceback. Do not overwrite or delete your user data to troubleshoot.
- **Packaged startup log:** Python startup exceptions are written to `startup-error.log` in the data directory. Rebuild with `build.ps1` if DLL imports fail; it uses a clean build-time PATH to avoid incompatible helper-tool libraries. This does not modify your persistent system PATH.
- **Backup/restore:** close Recall; copy the full data directory and any separately configured library directory. Copying only SQLite without managed files breaks re-indexing. Existing library paths are absolute. There is no built-in backup/relocation wizard yet.
- **GitHub workflow permission:** the current credentials can publish source but lack `workflow` scope. `docs/ci/windows-tests.yml` is an optional template, not active CI. To enable it later, authorize a credential with workflow permission and copy it to `.github/workflows/tests.yml`. No automated GitHub Actions run is claimed.
